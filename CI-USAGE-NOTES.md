# CI Usage Notes

This branch adds a short note about how our release checks are automated end to end.

## What's here

- A trivial workflow at `.github/workflows/audit.yml` on `main`,
  triggerable on demand via `workflow_dispatch`.
- This `notes/ci-usage` branch carries a small notes file.
- A draft pull request titled "Add CI usage notes" brings this branch into `main`.
- The workflow was dispatched once so there is a real run to inspect.
